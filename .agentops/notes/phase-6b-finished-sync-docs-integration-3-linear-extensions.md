Completed all four deferred pieces of Phase 6 (Module 9 webhook auto-kickoff). (1) sync-docs now runs during dispatch: extracted agentops_mcp::sync_docs (registry + GitHub search, no interactive prompt) out of agentops-cli's monolithic sync_docs, so the webhook receiver (no terminal available) can call it too, non-fatally on failure. (2) push_status/sync_push gained an optional custom_state_name parameter for teams with custom workflow states beyond the generic 5 (e.g. Testing), plus a --status-name CLI flag; AutoKickoffTeamConfig gained a status_name_map field as groundwork for auto-kickoff itself pushing statuses later. (3) agentops_llm::summarize_task_activity generates technical/non-technical/client-friendly summaries from a task's SessionEvents in one Anthropic call, delimiter-tagged and parsed back out, reusing tool_get_task_activity's exact rendering format so there's no second divergent copy of it; new agentops_linear::post_comment (commentCreate mutation, confirmed via live GraphQL introspection: issueId/body); new agentops task summarize CLI command posts technical+non-technical to Linear if the task is synced, prints all three either way. (4) agentops_repo_access::push_repo ships as a tested library function only, never --force, with no REST endpoint yet because there is no existing reconciliation between ConnectionStore's (remote url, encrypted key) and AutoKickoffTeamConfig's (repo_path); AGENTS.md generation gained a hardcoded no-Co-Authored-By-trailer instruction in the Commit/PR guidelines section, since AgentOps itself never creates git commits, so trailer hygiene has to live in the prompt coding agents read, not a git-rewrite capability AgentOps would own. All four pieces unit-tested (wiremock for Linear/Anthropic calls, a real local bare-repo push for push_repo); cargo test --workspace and cargo clippy --workspace --all-targets both green on the root and agentops-heavy workspaces, no new warnings introduced.
