# Contributing

## Current status: not accepting external contributions yet

Forking and pull requests are disabled while this project stabilizes. This isn't personal — it's a deliberate, temporary choice to avoid the flood of low-effort/AI-generated pull requests that has hit a lot of open-source projects recently. Forking and PRs will be re-enabled once the project is ready for outside contributors.

**In the meantime**: please open an issue if you've found a bug or have a feature request. Issues stay open — see the templates when you file one.

## When contributions reopen: ground rules

These will apply once forking/PRs are back on:

- **Disclose AI use.** If you used an AI tool to help write or investigate something, say so in the PR/issue description — which tool, and roughly how much of the change it produced. This isn't a ban on AI assistance, just honesty about it.
- **Explain it in your own words.** Don't paste a wall of raw AI-generated explanation as your PR description or issue write-up. A short, human summary of what changed and why is worth far more than a long generated one.
- **You're responsible for every line.** However a change was produced, you need to be able to explain why each part of it is there and why it's correct. If you can't, it shouldn't be in the PR.
- **Verify before you submit.** Especially for bug reports — reproduce it yourself first. An AI tool's claim that something is broken is not, by itself, a bug report.

## Reporting security issues

Don't file a public issue for a security vulnerability — see [SECURITY.md](./SECURITY.md).
