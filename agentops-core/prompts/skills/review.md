Invoke the codebase-review agent to audit the codebase against provided requirements documents.

Provide the documents to review against (PRDs, user stories, specs, or paste content directly). The codebase-review agent will:
1. Intake the documents and identify review scope
2. Draft a review plan (what areas to scan, what criteria to apply)
3. Execute a systematic scan
4. Produce an alignment report with ✅/🟡/❌/⚠️ status per requirement
5. Output a prioritized action plan (🔴 High / 🟡 Medium / 🟢 Low)
6. Save the report to the vault via vault-archivist

Use this skill when you have requirements and want to measure implementation completeness, or before a major release to catch gaps.
